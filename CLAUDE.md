# ActuallyAdditionsTiers

Tiered display stand variants (Iron, Gold, Diamond, Netherite) for Actually Additions. Each tier has a larger energy buffer and faster input rate, all pack-dev-configurable via server config.

## Architecture

The mod adds 4 new blocks but **no new BlockEntity classes**. All tier stands use AA's existing `TileEntityDisplayStand` BE class — this means:

1. AA's empowerer accepts them unchanged (its `instanceof TileEntityDisplayStand` check at `TileEntityEmpowerer.java:141` matches our blocks for free).
2. AA's BE renderer renders the placed item on top — no client code needed.
3. The energy NBT roundtrip, capability exposure, and `Clearable`/inventory machinery all come from AA.

The pieces that make this work:

- `TieredDisplayStandBlock extends BlockDisplayStand(false)` — inherits `newBlockEntity` (returns a `TileEntityDisplayStand`) and `getTicker`.
- `ITieredDisplayStand` marker interface with `aatiers$tier()` — block implements it; mixin checks it.
- `BlockEntityTypeAddBlocksEvent` listener in `ModRegistry` adds our blocks to AA's `DISPLAY_STAND` BE type's validBlocks set.
- `accesstransformer.cfg` strips `final` from `TileEntityDisplayStand.storage`.
- `TileEntityDisplayStandMixin` `@Inject(at = TAIL)` on the constructor: if the BE's block is `ITieredDisplayStand`, replace `storage` with a config-sized `CustomEnergyStorage`.

## Tier defaults (config-overridable)

| Tier | Capacity (FE) | Max Input (FE/t) |
|---|---|---|
| AA stock | 80,000 | 1,000 |
| Iron | 400,000 | 5,000 |
| Gold | 1,000,000 | 15,000 |
| Diamond | 4,000,000 | 40,000 |
| Netherite | 8,000,000 | 100,000 |

Server config: `config/aatiers-server.toml`, key `tiers.<name>.{capacity,maxInput}`. Changes apply on world reload.

## Build / dev

```bash
./gradlew build       # produces build/libs/actuallyadditionstiers-<version>.jar
./gradlew runClient   # dev client
./gradlew runServer   # dev server
```

## Texture/resource generation

`tools/generate_assets.py` reads AA's source textures and emits:
- 4 tier texture sets (top, side, base) into `assets/aatiers/textures/block/`
- blockstates, block models, item models, lang, loot tables, recipes

Tint params live at the top of the script — `TINT_STRENGTH`, `ACCENT_STRENGTH`, `ACCENT_LUMA_THRESHOLD`, and the per-tier RGB colors in `TIERS`. Re-run after editing:

```bash
python tools/generate_assets.py
```

Requires Pillow (`pip install pillow`).

The Python script regenerates JSON resources too — if you edit a generated JSON by hand, the next run overwrites it. Treat the script as the source of truth for everything under `assets/aatiers/{blockstates,models,textures}` and `data/aatiers/{loot_table,recipe}`.
